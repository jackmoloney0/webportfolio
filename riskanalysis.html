Portfolio Risk Analyzer

Multi-asset risk, return & volatility in one clean dashboard.

Executive Snapshot

This Python-based tool ingests live market data, computes asset-level statistics, and aggregates them into a single portfolio view — covering annualised return, volatility, covariance structure, and Sharpe ratio.

Focus Risk & Return

Annualised return and volatility across a custom basket of assets.

Method Covariance Model

Portfolio risk computed using covariance matrices & weight vectors.

Tech Python Stack

Built with NumPy, Pandas, Matplotlib, and yfinance for price data.

Methodology

1. Data Ingestion

Uses yfinance to download adjusted closing prices for a set of tickers, aligned into a clean historical price matrix.

2. Return & Covariance Model

Computes daily returns, annualises mean and volatility, and constructs a covariance matrix to capture relationships between assets.

3. Portfolio Construction

Applies user-defined weights to derive portfolio-level return, risk, and Sharpe ratio, then visualises key outputs in a dark, Citadel-style layout.
