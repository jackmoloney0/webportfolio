Portfolio Risk Analyzer

Multi-Asset Risk, Return & Volatility.

Overview

This Python-based tool ingests live market data, computes asset statistics, and puts them into a single portfolio view covering yearly return and volatility, covariance structure and sharpe ratio.

Methodology

1. Data Ingestion

Uses yfinance to download adjusted closing prices for a set of tickers, aligned into a clean historical price matrix.

2. Return & Covariance Model

Computes daily returns, annualises mean and volatility, and constructs a covariance matrix to capture relationships between assets.

3. Portfolio Construction

Applies user-defined weights to derive portfolio-level return, risk, and Sharpe ratio, then visualises key outputs in a dark, Citadel-style layout.
