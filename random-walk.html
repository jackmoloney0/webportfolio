Random Walk Simulator

A visual engine for exploring how uncertainty compounds over time in asset prices.

Project Snapshot

  • Simulates hundreds of price paths in one run.
  • Configurable steps, volatility and starting value.
  • Outputs distributions, trajectories and volatility patterns.
  • Built with Python, NumPy & Matplotlib.

Overview

This simulator models a discrete-time random walk for a synthetic “stock” price. At each step, the price is updated by adding a random shock drawn from a Gaussian distribution. By running many paths in parallel, you can see how small random changes accumulate into very different end prices.

The page is designed to feel like a cross between a quant lab interface and a polished product page: dark, focused, but clean and minimal so the math and visuals remain the centre of attention.

Simulation Parameters

Number of Paths

Runs hundreds of independent simulations to form a distribution of outcomes.

Steps per Path

Each path is evolved over many time steps to show long-horizon behaviour.

Volatility Input

Volatility controls the scale of each shock, directly impacting dispersion.

How It Works

1. Initialise

Set a starting price S₀, choose the number of paths, steps, and volatility level.

2. Evolve the Paths

At each time step, update: S(t+1) = S(t) + ε, where ε ~ N(0, σ). Each path evolves independently.

3. Analyse the Spread

Compare trajectories, inspect the final price distribution, and link visual uncertainty to statistical intuition about volatility and risk.

Built with Python, NumPy and Matplotlib in a research-style workflow, designed for clarity and experimentation.
